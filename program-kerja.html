Program Kerja

Program kerja Pusat Penjamin Mutu dalam mendukung implementasi Sistem Penjaminan Mutu Internal (SPMI) secara berkelanjutan.

Tentang Kami Struktur Organisasi Sasaran Mutu Program Kerja

Program Kerja Pusat Penjamin Mutu

Pusat Penjamin Mutu menyusun program kerja tahunan yang selaras dengan Renstra universitas dan standar SPMI. Setiap program dirancang untuk mendorong pencapaian sasaran mutu secara terukur.

01

Sosialisasi SPMI

Menyelenggarakan sosialisasi dan workshop SPMI bagi pimpinan unit, program studi, dosen, dan tenaga kependidikan untuk meningkatkan pemahaman tentang kebijakan mutu.

02

Audit Mutu Internal

Melaksanakan audit mutu internal secara terjadwal ke seluruh program studi dan unit kerja, dilanjutkan dengan monitoring tindak lanjut temuan.

03

Pendampingan Akreditasi

Memberikan pendampingan intensif kepada program studi yang akan menghadapi akreditasi, termasuk penyiapan borang dan dokumen pendukung.

04

Pengembangan Dokumen Mutu

Menyusun, mereview, dan memutakhirkan dokumen mutu meliputi pedoman SPMI, standar SPMI, borang, dan instrumen monitoring.

05

Pelatihan Auditor

Menyelenggarakan pelatihan dan sertifikasi auditor mutu internal untuk memperkuat kapasitas tim audit di lingkungan universitas.

06

Rapat Tinjauan Manajemen

Menyelenggarakan rapat tinjauan manajemen secara berkala untuk mengevaluasi pencapaian mutu dan merumuskan tindak lanjut strategis.

Penjadwalan Program

Seluruh program kerja dilaksanakan berdasarkan kalender akademik dengan jadwal yang telah ditetapkan pada awal tahun. Evaluasi program dilakukan setiap akhir semester sebagai bahan perbaikan periode berikutnya.
